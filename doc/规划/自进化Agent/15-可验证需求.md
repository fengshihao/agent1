## 开发节奏（每层必验）

```text
取 REQ → 写单测/集成测 → 实现 → CLI 无 LLM 验 →（有 Key）LLM UC 验 → 审 events.jsonl → 勾 REQ → 再取下一 REQ
```

**禁止**：一次性实现 V4～V5 再补测；**允许**：V4 中 REQ-060 先于 REQ-070。

---

## 日志审查要点（每次 E2E 后）

| 看什麼 | 优化信号 |
|--------|----------|
| tool 次数是否过多 | 提示词/Coach 补「先 read capabilities」 |
| 重复失败 execute_script | 行号或 snippet 不清 |
| 尝试 write catalog | REQ-020 或 Coach 不够 |
| 未 install 就 ensureNative | capabilities 或 Coach missing_native |
| promote 过早 | 应提醒 staging 规范 |
