## 真实 LLM 端到端协议（你有 Key 之后）

```bash
# DeepSeek 等 OpenAI 兼容：见 e2e-runs/DeepSeek-省钱E2E.md 与 scripts/e2e-deepseek-env.example.sh
source /path/to/your-env.sh   # 含 OPENAI_API_KEY，勿提交仓库
./agent1 "（对应用例的用户原话）"
```

**省钱**：`AGENT1_MAX_TURNS_PER_RUN=4` 等；优先 Scripted 测工具，再真实 LLM。问题优先改 **工具/权限/错误结构**，少靠针对单 UC 的长提示词。

**每次跑完必做：**

1. `tail -n 50 "$AGENT1_AGENT_ROOT/logs/events.jsonl"`（或 `ProductivityLogsCommand`）  
2. 看 **tool 序列**是否越权、是否该 install 却 read 全库、是否重复失败脚本  
3. 保存 **transcript.jsonl** 片段进用例记录（可 redact key）

**通过标准**：自动化断言 + **人工日志结论「行为合理」** 双勾；仅单测绿不算 UC 过。
