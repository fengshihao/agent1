# 02 — 目录与权限模型

## 根：`agentRoot`

与现有生产力路径一致，由 `AGENT1_AGENT_ROOT` 指定；未设置时 CLI 当前默认项目下 `.agent1`，事件路径工具类默认 `~/files/agent`（**两处默认需在实现阶段统一**，见 [04-与现状对照.md](./04-与现状对照.md)）。

建议的**目标布局**（自进化完整形态）：

```text
<agentRoot>/
├── agent.manifest.json      # 自省入口：版本、能力清单、路径说明、组件列表
├── logs/
│   └── events.jsonl         # 全局事件（已有）
├── docs/
│   ├── system/              # 出厂说明：目录结构、工具边界（工作 Agent 只读，见 06）
│   │   ├── README.md
│   │   ├── directories.md
│   │   └── tools-and-quickjs.md
│   └── capabilities/        # 能力索引（仅 Promotion API 写入；工作 Agent 只读）
├── sync/                    # 云端清单对比状态（见 08）；仅 sync 模块写
│   ├── state.json
│   └── pending.json         # 可选
├── shared/                  # 公共区：Session 只读
│   ├── catalog/             # 云端 sync 落盘（skills/scripts/libs）
│   ├── local/               # Promotion API 写入的用户进化
│   ├── templates/
│   └── mcp/
└── sessions/
    └── <sessionId>/
        ├── meta.json
        ├── transcript.jsonl
        ├── runs/
        │   └── <runId>.json
        ├── workspace/         # Session 沙箱根（工具 RW 边界）
        │   ├── artifacts/     # 已有
        │   ├── .spill/        # 已有
        │   ├── notes/         # 可选：本 Session 私有笔记
        │   └── staging/       # 可选：待晋升草稿（skill/script 提案）
        └── session.summary.md # 可选：本 Session 结构化总结（总结 Agent 产出）
```

## Session 沙箱（你提到的「只能访问这个目录可读写」）

对齐现有 `WorkspaceSandbox` 语义：

- **读写**：`<agentRoot>/sessions/<sessionId>/workspace/**`（及未来若扩展，仍须路径 containment）。
- **只读（逻辑层）**：`shared/**`、`docs/**`（扩展 `read_file` 多根，或专用 `read_agent_doc`）。
- **禁止**：工作 Agent 用 `write_file` / `edit_file` 等改区外；区外写入**仅** [Promotion API](./06-环境文档与区外写入.md)（初版审查侧自动同意 + 事后审计）。

> 说明：「GitGS」已确认为 **QuickJS** 口误；脚本约定见 `docs/system/tools-and-quickjs.md` 与 [06-环境文档与区外写入.md](./06-环境文档与区外写入.md)。

## 公共区 `shared/`

| 子目录 | 用途 | Session 内典型用法 |
|--------|------|-------------------|
| `shared/catalog/*` | 云端同步官方/策展资源 | 只读；更新见 [08-云端资源同步.md](./08-云端资源同步.md) |
| `shared/local/skills/` | 用户晋升 Skill | 加载时可覆盖 catalog 同名 |
| `shared/local/scripts/` | 用户晋升脚本 | `execute_script` / QuickJS |
| `shared/templates/` | 晋升时复制的起点 | 写 workspace 前复制模板 |
| `shared/mcp/` | MCP 清单与连接说明 | 自省与配置助手读取；密钥仍走 env/密钥存储 |

**命名与版本**：建议每个晋升条目带 `id`、`version`、`sourceSessionId`、`promotedAt`，避免同名覆盖 silent break。

## 文档区 `agentRoot/docs/`（与仓库 `doc/` 的关系）

- **仓库 `doc/`**：项目级设计、规范、路线图（**本规划系列**放这里）；开发用，不假定用户 Agent 能写。
- **运行时 `agentRoot/docs/system/`**：我们写好的**环境自述**，工作 Agent **只读**，用于理解目录与 QuickJS/工具边界（详见 [06-环境文档与区外写入.md](./06-环境文档与区外写入.md)）。
- **运行时 `agentRoot/docs/capabilities/`**：随 `shared/` 增长的索引；**仅 Promotion API 写入**，工作 Agent 只读。

## 权限矩阵（2026-09-27 共识）

| 路径 | 工作 Agent 读 | 工作 Agent 写（文件工具） | 区外写入通道 |
|------|---------------|---------------------------|--------------|
| `sessions/<id>/workspace/` | ✓ | ✓ | — |
| `sessions/<id>/transcript.jsonl` | ✓（经 chat_history） | ✗（运行时 append） | — |
| `shared/local/` | ✓ | ✗ | Promotion API |
| `shared/catalog/` | ✓ | ✗ | sync apply（CLI/专用工具） |
| `sync/` | ✗ | ✗ | sync 模块 |
| `docs/system/` | ✓ | ✗ | 仅安装/升级包 |
| `docs/capabilities/` | ✓ | ✗ | Promotion API |
| `logs/events.jsonl` | 经 logs 子命令 | ✗ | 运行时 append + audit |

## 自省：`agent.manifest.json`

供系统提示与专用「meta 工具」读取，建议包含：

- `agentRoot` 各子目录说明；
- 当前加载的 skill/script/mcp 数量与扫描路径；
- 运行时限制（`AgentRuntimeDefaults` 摘要）；
- 指向 `docs/README.md` 与最近 Session 列表的指针（非全量 transcript）。

这样 Agent 在回答「你是谁、你能动什么、数据在哪」时有**单一事实来源**。
