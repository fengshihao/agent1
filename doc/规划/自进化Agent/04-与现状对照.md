# 04 — 与现状对照

## 已有（生产力路径）

| 能力 | 实现位置 | 说明 |
|------|----------|------|
| Session 目录 | `FileSessionStore` | `sessions/<id>/meta.json`、`transcript.jsonl`、`workspace/artifacts`、`workspace/.spill` |
| Run 落盘 | `FileRunStore` | `sessions/<id>/runs/<runId>.json` |
| 工作区沙箱 | `WorkspaceSandbox` | 相对路径、防逃逸 |
| 系统提示词 | `ProductivitySystemPromptBuilder` | 仅有工作区路径/日期/OS；**缺** agentRoot 树、权限、晋升职责（见 07） |
| 工作区工具 | `Read/Write/Edit/ListDir` | 仅 sandbox 内 |
| 对话检索 | `ChatHistoryTool` | 当前 Session transcript |
| 脚本 | `ExecuteScriptTool`、`MutableScriptToolBridge` | CLI 已接 Weizhi 环 |
| 事件 | `AgentDataPaths.eventsJsonl` | 默认 `~/files/agent/logs/events.jsonl` |
| Agent 根 | `ProductivityCli.resolveAgentRoot()` | 默认 `<cwd>/.agent1` |

## 已有（经典 CLI）

| 能力 | 说明 |
|------|------|
| Skills | 从**仓库** `.claude/skills/*/SKILL.md` 加载，`SkillTool` 执行 |
| Bash/Python | 不受 Session workspace 约束（经典路径），与生产力沙箱哲学不同 |

## 差距（相对自进化目标）

1. **无 `shared/`、`agentRoot/docs/`、`agent.manifest.json`** — 公共层与活文档未落地。
2. **Skill 未与生产力 Session 绑定** — 自创 Skill 无晋升路径。
3. **agentRoot 默认值分裂** — `ProductivityCli` 与 `AgentDataPaths` 默认路径不一致，进化数据可能散落在两处。
4. **无总结/晋升 Agent 编排** — `ProductivityAgentHost` 仅有工作循环。
5. **跨 Session 自省 API** — 需 `list_sessions`、读 summary、读 manifest、只读扫 `shared/` 的工具化。
6. **MCP** — 规划位在 `shared/mcp/` + `docs/capabilities/mcp.md`，代码集成待排期。
7. **云端 catalog 同步** — 无 manifest diff / CDN 拉取 / `shared/catalog/`（见 08）。
