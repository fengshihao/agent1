## 总顺序（依赖）

```text
阶段 1 地基 → 阶段 2 自知 → 阶段 3 权限+Coach
    → 阶段 4 行号 D1–D4 【门禁】
    → 阶段 5 Catalog 同步与 AI 安装（可与 4 部分并行，见各步标注）
    → 阶段 6 晋升 M3
    → 阶段 7 收尾（native 宿主、Skill 合并、可选 M4）
```

**本迭代不做**：MCP、Android catalog、manifest 签名、rsync 块级、用户事前审批。

## 验收用「一条演示脚本」（产品）

1. 新 Session，AI 从提示词知 catalog/sync。  
2. 用户要缩略图 → AI 读 capabilities → `catalog_install(native.image_resize)`。  
3. workspace 写 `.js`，`execute_script`；若错行，**userLine 准**。  
4. 用户要复用 Skill → staging → `promote_request` → 下轮 local skill 可用。  
5. 全程无 write catalog；events 可审计。
