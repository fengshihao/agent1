# shell-helper reference

## Suggested first commands

- `pwd`
- `ls`
- `git status --short`
- `rg "<keyword>" .`

## Git read-only checks

- `git status`
- `git diff`
- `git log --oneline -n 10`

## Notes

- Keep commands focused and explain intent in plain language.
- If a command may take time, mention expected runtime before running it.
